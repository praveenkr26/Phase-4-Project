# 🚀 Phase 4 AI Project – Gemini API Content Generator

A modern AI-powered content generator built using **Vanilla JavaScript**, **Node.js**, **Express.js**, and **Google Gemini API**.  
This project allows users to generate intelligent text responses based on prompts using Google's advanced AI model.

---

## 📌 Project Overview

This is a **Phase 4 learning project** where I built a full-stack AI tool without using any frontend frameworks.  
It demonstrates how to integrate a powerful AI API into a real-world web application.

---

## ⚙️ Tech Stack

- 🌐 Frontend: HTML, CSS, JavaScript (Vanilla JS)
- 🖥️ Backend: Node.js, Express.js
- 🤖 AI Model: Google Gemini API
- 📦 API Handling: Fetch / REST API
- 🧠 Environment: Dotenv

---

## ✨ Features

- 🔥 AI text generation from user prompts
- ⚡ Fast API response using Gemini model
- 🎯 Clean and simple UI
- 📱 Responsive design
- 🔐 Secure API key handling using environment variables
- 🧩 Modular backend structure
